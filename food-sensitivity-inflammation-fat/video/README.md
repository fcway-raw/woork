# 🎬 动画讲解视频（4 分钟，无配音，字幕版）

依据 [[02_旁白脚本与分镜]] 制作的纯前端动画：所有画面由时间 `t` 计算得出（可拖动、可逐帧渲染），旁白以字幕呈现，屏幕字为大标签。

## 预览
- 直接用浏览器打开 `index.html`（Chrome / Edge 均可）。
- 底部工具栏：播放 / 暂停（空格键）、进度条、`第 N 幕` 跳转；← → 键快退快进 5 秒。
- 加 `?t=95` 从指定秒数开始；加 `?render=1` 隐藏工具栏（渲染用）。
- 需要本机有 `WenQuanYi Zen Hei` 或 `Noto Sans SC` 字体；无任何网络依赖。

## 修改字幕 / 屏幕字 / 徽章
打开 `index.html`，搜索 `DATA`，找到 `SCENES` 数组，每一段（beat）长这样：

```js
{sub:'旁白（作为字幕）', text:'屏幕字', badge:[['human','Erridge 2007']], card:'yellow'}
```
- `sub`：字幕，`**粗体**` 会高亮；`text`：顶部大字（可为空）
- `badge`：证据徽章，类型 `animal`🐭 / `cell`🧫 / `human`👥 / `case`👤，后面是引用文字
- `card`：`red` / `yellow` / `green` 标题卡样式；`pos:'center'` 让屏幕字放到画面中间
- 每幕 `start` / `end`（秒）来自脚本；每段的起止按旁白字数自动分配（至少 3.5 秒）
- 画面元素的编排在 `BUILD[n]` 函数里（第 n 幕），时间都是相对该幕开头的秒数

## 重新渲染 MP4
```bash
cd video
node render.mjs                      # 24fps，4 个页面并行，约 3 分钟
node render.mjs --keyframes ./kf     # 每段截一张中段关键帧，检查排版
node render.mjs --shot 95 a.png      # 截取指定秒数
```
依赖全局 `playwright`（自带 Chromium）和 imageio-ffmpeg 的 ffmpeg（路径、输出位置写在 `render.mjs` 顶部）。`*.mp4`、`frames/` 已在 `.gitignore` 忽略。

## 配音时间表（录旁白用）
“起/止”为视频时间（秒）。中文语速约 4–5 字/秒；个别段落旁白偏长（例如第 4 幕开头），配音时可加快或精简 `sub`。
